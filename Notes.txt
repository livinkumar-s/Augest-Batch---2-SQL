Join 
-------
>> Joins are used to combine 2 or more tables.

Inner Join 
------------
>> It retrives only the matched records from both tables.
>> unmatched records will be ignored.
Ex: SELECT * FROM tb1 INNER JOIN tb2 ON relationship;

Left Outer Join 
---------------
>> It retrives all from left table.
>> only matching records from right table.
Ex: SELECT * FROM tb1 LEFT JOIN tb2 ON relationship;

Right Outer Join 
---------------
>> It retrives all from right table.
>> only matching records from left table.
Ex: SELECT * FROM tb1 RIGHT JOIN tb2 ON relationship;

Full Outer Join 
---------------
>> It retrives all from both tables.
Ex: SELECT * FROM tb1 RIGHT JOIN tb2 ON relationship
UNION
SELECT * FROM tb1 RIGHT JOIN tb2 ON relationship

Cross Join
