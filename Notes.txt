Datatypes 
------------
Numeric datatypes 
-------------------
INT --> whole numbers.
FLOAT --> Decimal Numbers.
BIGINT --> Large Whole Numbers 
DOUBLE --> Large Decimal Numbers

String datatypes 
-------------------
CHAR(l) --> fixed length char string. Ex: CHAR(5) --> "Hello", "Hi Hi", "Hi", "Anitha" 
VARCHAR(l) --> variable length char string. Ex: VARCHAR(5) --> "Hi","Hello", "Excellent"
TEXT --> paragraph 

Boolean 
---------
BOOLEAN --> 1 or 0

DATE and TIME 
--------------
DATE --> "yyyy-mm-dd"
TIME --> "HH:MM:SS"
DATETIME --> Both

Constraints 
---------------
Rules that are applied to a column.

Primary Key ---> identify the records uniquely. no duplicates, no nulls(empty cell). (gets indexed defaultly)(adds index)
Foreign Key --> to relate 2 tables (parent - child). refferential integrity.

UNIQUE --> No duplicates
NOT NULL --> No empty cells
DEFAULT --> gives default value
CHECK --> insert records conditionally. CHECK (cond)
AUTO_INCREMENT --> generates sequence of numbers record by record.
ENUM (v1,v2,v3) --> GENDER ("male","female")

BETWEEN  --> range filtering 
---------
>> inclusive range 
Ex: ....WHERE col BETWEEN n1 AND n2;

IN, NOT IN  
------------
Ex: .... WHERE col IN (v1,v2.....)

LIKE  
------
Pattern Matching.
Ex: ...where col LIKE pattern;

wildcard 
-------------
% --> matches 0 to infinite chars 
_ --> matches only one char.

starts with a --> "a%" --> "anand", "anshiya", "a"
end with a --> "%a"

"___a" --> "arun", "guna"

ORDER BY 
----------
>> arrange the records either in ascending or desc.
Ex: ... ORDER BY col asc/desc;

LIMIT/OFFSET 
-------------
>> limit the records.
>> offset skip first few records.

Queries 
---------
To create a Database ---> CREATE DATABASE dbname;
To Select database --> USE dbname;
To create table --> CREATE TABLE tbname (
    col dt constraint,
    col dt constraint,
    col dt constraint,
    col dt constraint
    .
    .
);

To insert data --> INSERT INTO tbname (col details) VALUES (),(),().....
To Retrive data --> SELECT (col details(*)) FROM tbname;
To Update a record --> UPDATE tbname SET col=val;
To delete a record --> DELETE FROM tbname;

Safe update mode --> You can update/delete only one record in one go. Where clause is must. condition should depend on PK.
